# LifeXP

LifeXP turns daily goals into an RPG-style progression dashboard with a dark forest-green theme. Quests, habit check-ins, XP, streaks, profile settings, achievements, and reward claims are saved in the browser with local storage. The **Guide** menu button explains how each part works.

## Run it locally

Requires Node.js 20.19+ or 22.12+, plus npm (or pnpm).

```sh
npm install
npm run dev
```

Open the local address printed by Vite. For a production build:

```sh
npm run build
npm run preview
```

After building, you can also serve the static production files with Node.js alone:

```sh
npm start
```

The first launch starts with an empty quest and habit list, level 1, and 0 XP. Add your own quests and habits to begin. Use **Profile settings** to personalize the adventurer profile.

Open **Settings** in the side menu to choose from six background palettes and ten additional system fonts, or reset the saved profile and progress. The **Guide** menu explains how quests, habits, rewards, and progression work.
